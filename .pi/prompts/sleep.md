执行 sleep 巡检（正反旋转：平时阴约束阳，睡眠时阴驱动阳——脚本对账列清单，你照单执行，元独占裁决）。

严格按以下五步走，不得跳步、不得自行拍板裁决：

## ① 机械对账（零 LLM，只跑脚本）

```
python3 bcp/evolve.py
python3 bcp/check.py --selfcheck
```

## ② 列清单

把两份报告中的全部待处置项（死重候选 / 降级候选 / 幽灵注册 / IDLE 项 / 晋升候选）整合为
checklist，落盘 `bcp/sleep/<YYYYMMDD>-sleep.md`，每条一行 `- [ ]`，格式：
`- [ ] <项> ｜ 来源：<报告节> ｜ 建议：<处置>`

## ③ 呈元裁决（能垒——你不得代裁）

把清单逐条呈给用户，每条要一个明确裁决：`PROMOTED` / `REJECTED` / `降级` / `删除` / `挂起`。
无裁决的条目只能标「挂起」，不得自行处置。

## ④ 执行 + 打勾

按裁决逐条处置（改文档/删文件/落账），每完成一条把清单上该条改为 `- [x]`。

## ⑤ 结束（醒来）

清单全部 `[x]`（或显式挂起）后：

1. 删除清单文件（过程可丢，账本留痕）
2. 重跑 `python3 bcp/evolve.py` —— REPORT 落账即 sleep 结束，活动量计数归零，sleep 闸自动重置
3. 向用户报告：本次裁决计数（晋升/拒绝/降级/删除/挂起）
